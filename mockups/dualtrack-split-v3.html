V3.1 变更(在 V3 基础上,来自第二轮命名评审):① 收益 balance → pnl(balance 更像账户余额,这里展示的是 PnL 汇总);② Context图 → 大级别图(中文页面不夹英文,slug 仍是 context,同一 widget 两个 slot 实例);③ 新增 风险 risk(杠杆/保证金/最大可亏/强平距离/SL 有效性,原来散落在持仓/下单里);④ 新增 数据 data(数据源/新鲜度/K线类型/bar 数量,一等公民化,不再只是图表 header 里一行小字);⑤ 归因+判卷+台账 合并为复盘 review 一个 widget(三个分节,不再是三张卡片);⑥ 判卷分节里"关键位"/"信号"两行改为显式"未建立评分口径"(灰态,不给 ✓/✗)——后端 _grade_plans() 目前只做 direction-only 评分,继续假装三项都评分过是在编造;⑦ 状态 widget 移除"已评分..."内容,运行健康度和复盘判断分开;⑧ 阶段 phase 正式收录进注册表(仍以画布头部页签实现,补了 data-widget 标记方便工程定位)。其余延续 V2/V3:零共享、双画布、相位页签、整列置灰、TP/SL 前高前低可拖、判卷各轨自评不做跨轨头对头计分条(已与所有者确认)。
