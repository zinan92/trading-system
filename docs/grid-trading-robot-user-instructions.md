# Extended 网格交易机器人用户指令集

版本：2026-07-15  
适用页面：[Goldbot v5](https://goldbot.park-ai-intel.com/dashboard-v5.html)  
适用范围：当前 `PAPER` 环境；不代表实盘资金已经接入

## 一分钟理解

这个页面只有一个生产策略、一个 paper ledger 和一套真实 paper 挂单。图上的“待启动预览”不是订单；只有明确点击“启动机器人”，并同时看到“运行中 · N 笔挂单”和“当前委托”中的订单，才算真正启动。

当前所有获授权用户共享同一个 paper 机器人和 ledger。给别人使用时，建议指定一个操作人，其余用户只观察。

## 哪些地方需要解释

| 页面位置 | 是否需要解释 | 用户必须知道什么 |
| --- | --- | --- |
| `PAPER` | 必须 | 当前是模拟账本，不会向实盘券商发单。 |
| 行情、来源、更新时间 | 必须 | 只有“实时·可信”才允许新开仓；陈旧、缺失或 synthetic 行情会 fail closed。 |
| K 线周期 | 必须 | 只改变图表观察周期，不改变网格 Range、间距或资金。 |
| 刷新趋势 | 必须 | 重新读取固定 D1/4H/1H 数据并运行一次 AI 市场评估，只产生建议，不改生产计划、不撤单、不下单。 |
| 规则评分 | 必须 | 是确定性规则评分，当前未做历史概率校准，不是胜率。 |
| AI 自评 | 必须 | 是模型对本次材料充分性的 1–10 自评，不是概率。 |
| 中性 / 做多 / 做空 | 必须 | 改变挂单方向；不会偷偷移动同一市场证据得到的 Range。 |
| 稳健 / 激进 | 必须 | 改变 D1 Range 倍数、4H 间距目标和风险预算。 |
| 智能填充 | 必须 | 用确定性风险引擎计算参数并画预览；不下单。 |
| 每格数量（名义） | 必须 | 单位是 USD 名义金额，不是黄金数量。 |
| 杠杆上限 | 必须 | 是硬上限，不代表系统一定用满；风险预算可能把实际杠杆压得更低。 |
| 启动机器人 | 危险操作 | 创建生产策略版本并向 paper ledger 提交网格限价单。 |
| 停止 + 撤单 + 平仓 | 危险操作 | 撤销未成交委托，并用最新可信价格平掉当前持仓。 |
| 运行中调整 | 危险操作 | 按当前整格间距扩展或收缩边界；只增撤边缘未成交入场单，每格金额、已有持仓与 TP/SL 不变。 |
| 手动平仓 | 危险操作 | 只平所选持仓，不会自动停止机器人或撤销其他挂单。 |
| Strategy Shadows | 必须 | 历史反事实比较，不产生生产订单，不修改 paper ledger。 |

## 如何启动机器人

### 1. 登录

1. 打开 Goldbot v5。
2. 输入获授权邮箱和 Cloudflare 一次性验证码。
3. 登录有效期为 7 天；过期后重新验证。

### 2. 启动前检查

必须同时满足：

- 顶部显示 `PAPER`；
- 行情显示 `实时·可信`，且来源和更新时间正常；
- 状态是 `已停止` 或 `新周期待启动`；
- 账户、订单、持仓与成交没有无法解释的缺失；
- 绿色启动按钮可点击。

出现行情陈旧、synthetic、运行异常、数据突然为空或风险数值无法解释时，不要启动。

### 3. 生成预览

1. K 线周期按观察需要选择；它不会改变策略参数。
2. 选择方向：中性、做多或做空。
3. 选择风格：稳健或激进。
4. 点击“根据当前行情智能填充参数”。
5. 核对 Range、网格数、间距、每格名义、杠杆上限、预计保证金和最大亏损。
6. 核对 K 线图上的预览网格。

此时仍未下单。

### 4. 真正启动

点击绿色“启动机器人”后，后台会：

1. 再次验证行情可信、新鲜且非 synthetic；
2. 用页面参数创建新的生产策略版本；
3. 让每笔订单关联 `strategy_plan_id` 和版本号；
4. 向 paper execution 提交限价单；
5. 只有订单被接受后才进入“运行中”。

启动成功必须同时看到：

- `运行中 · N 笔挂单`，且 `N > 0`；
- 绿色按钮变暗，红色停止按钮变明显；
- “当前委托”有真实订单；
- 图上显示生产挂单，而不是“待启动预览”。

## 刷新趋势与 AI 是怎样工作的

### 刷新趋势会做什么

点击后，后台会读取：

- 最近完整的 D1、4H、1H、15m 可信行情；
- ATR14、EMA20、EMA50、MACD(12/26/9)、趋势方向、变化幅度和方向效率；
- 当前生产计划；
- 当前账户状态；
- 上一周期复盘。

AI 只建议两个会影响预览的选择：

- `direction`：中性、做多或做空；
- `style`：稳健或激进。

AI 还必须返回直白理由、关键位和实际使用的证据。Range、间距、网格数、每格资金和杠杆不是 AI 随口生成，而是随后由确定性风险引擎计算。

刷新结束后只保存一份 AI `PlanProposal`。用户必须点击“将该建议载入参数预览”，再明确启动或调整，生产计划才可能改变。

### AI 看到了什么、如何分析

本次 prompt 的完整业务内容会与提案一起保存。它包含固定 D1/4H/1H 摘要、当前计划、账户和复盘，并要求 AI：

- 分别解释 D1、4H、1H 证据；
- 材料冲突时明确写出冲突；
- 信息不足时不得静默补全；
- 不得输出概率、胜率或数值网格参数；
- 图表周期不得作为策略输入。

仓库没有另一段隐藏的业务 system prompt。页面的“查看 AI 输入与提示词契约”可查看本次 prompt 版本和输入来源。

### 如何查看本次 Input / Output

每次刷新成功后，“当前趋势识别”下方会出现“AI 评估收据”。打开后可以看到：

- **Input**：D1、4H、1H、15m 各自的数据来源、完整 K 线数量、起止时间、最新收盘、ATR14、EMA20、EMA50、MACD 线/信号线/柱体；
- **Prompt**：本次实际发送给 AI 的完整业务提示词；
- **Output**：AI 原始 JSON、解析后的方向/风格/理由/关键位；
- **规则校验**：周期一致性、信号强度、状态适配、数据健康和历史校准分；
- **副作用**：本次是否改变生产计划、是否创建订单；
- **留档证明**：本地 JSON 路径和 SHA256。

AI 并不是观看一张截图。它读取的是已经完成的 OHLC K 线数字和后台计算出的指标快照。15m 只用于短周期确认，不能改变 D1 Range 和 4H spacing 合同。

每次成功或失败的评估都会独立保存到：

```text
outputs/dualtrack/strategy_control/evaluations/<cycle_id>/<timestamp>_<evaluation_id>.json
```

文件 schema 为 `strategy-ai-evaluation-v1`。即使两次评估得到相同方向，也会保留两份独立收据。

### 为什么不再显示“置信度 100%”

旧页面把失败占位计划中的 `confidence=1` 错误换算成了 `100%`。这个显示已经移除。

现在页面分开显示：

- **规则评分 /100 · 未校准**：D1/4H/1H 一致性、信号强度、市场状态适配和数据健康的确定性评分；历史校准分目前为 0。
- **AI 自评 /10 · 非概率**：模型认为本次推理材料是否充分。

两者都不是盈利概率，不能单独作为启动依据。

## 网格怎样计算

### 固定策略视角

| 周期 | 固定用途 |
| --- | --- |
| D1 | 用最近 14 个完整、非周末日线计算长期 Range |
| 4H | 用最近 14 根完整 4 小时 K 线计算目标间距 |
| 1m | 执行、更新和突破确认 |
| 页面 K 线周期 | 只供观察，不参与策略计算 |

### Range

以启动预览时的可信价格 `P` 为中心：

```text
稳健 half_range = 2 × D1 ATR14
激进 half_range = 1 × D1 ATR14

下边界 = P - half_range
上边界 = P + half_range
```

中性、做多和做空使用相同 Range。方向只改变哪一侧挂单：

- 中性：当前价下方挂买单、上方挂卖单；
- 做多：只启用当前价下方买单；
- 做空：只启用当前价上方卖单。

### 间距和网格数

```text
稳健目标间距 = max(0.25 × 4H ATR14, 成本保护间距)
激进目标间距 = max(0.125 × 4H ATR14, 成本保护间距)

自动网格数 = clamp(floor(Range 总宽度 ÷ 目标间距), 24, 80)
实际间距 = Range 总宽度 ÷ 自动网格数
```

成本保护间距至少覆盖估算往返成本的 5 倍。用户可手动填写 2–80 格，但自动模式始终使用 24–80 格。

### 杠杆和每格名义金额

账户权益为 `E`、用户杠杆上限为 `L`：

```text
绝对名义上限 = E × L

稳健资本预算 = 绝对名义上限 × 50%
激进资本预算 = 绝对名义上限 × 70%

稳健最大计划亏损 = E × 5%
激进最大计划亏损 = E × 8%
```

系统先按“同方向最多可能同时成交的网格数”计算资本上限，再按所有网格到止损位的最坏损失计算风险上限：

```text
每格名义 = min(资本允许的每格名义, 最大亏损允许的每格名义)
```

因此，10,000 U 权益、10x 杠杆上限虽然有 100,000 U 的绝对名义上限，但系统不会自动满仓。页面会显示实际杠杆；风险上限通常会让它明显低于 10x。

### TP、SL 和最大风险

- 每个网格的 TP 是相邻下一条网格线；
- 买单 SL 在 Range 下方再一格；
- 卖单 SL 在 Range 上方再一格；
- 中性模式按买侧或卖侧中较大的最坏损失计风险，不把互斥的两侧简单相加；
- 预计保证金也按最大同向敞口计算。

这些是 paper 风险估算，不保证真实市场滑点、跳空或流动性结果。

## 运行中怎样干预

### 只观察

可以切换图表周期、EMA/MACD、查看委托、持仓、成交、复盘、NAV 和 Strategy Shadows。图表周期不会改变运行中的网格。

刷新趋势也不会自动改变生产计划；它只产生新 proposal。

### 修改 Range 或网格参数

在“运行中调整”输入新边界并确认。后台会把输入值吸附到当前等价差间距或等比例比率，创建新计划版本，只新增外扩边缘挂单或撤销收缩范围外的未成交入场单。当前网格间距、每格名义金额、已有持仓及其 TP/SL 不会改变；历史 ledger 保留。

如果需要改变间距、网格数量逻辑、方向或每格金额，这不属于“运行中调整”。应使用停止后的新网格流程，避免把几何扩边伪装成仓位重配。

图表 Range 草稿的后台预览是只读的：拖动整体时保持宽度、格数和每格金额；拖动单边时固定另一边、保持格数和每格金额，并重新计算等价差或等比例。预览会返回完整原值 → 新值、当前风险和预计撤挂单数量，但不会写 StrategyPlan、撤单或下单。风险超限时只能显式选择“按风险预算重新计算每格名义”，系统不会暗改仓位。

只有先打开 K 线右上角的“调整网格”，Range 才会接管鼠标；普通状态仍用于拖动 K 线。Range 内部是抓手，上下边界是垂直双箭头。每次松开鼠标只保留半透明虚线草稿，可以继续微调；点击图上的小“确认”才打开原值 → 新值卡片，点击“取消”立即退出调整并恢复生产网格显示。

如果方向需要大幅反转，推荐先“停止 + 撤单 + 平仓”，确认归零后再重新启动，避免旧持仓和新方向挂单并存。

### 手动平仓

在“当前持仓”点击手动平仓，只会退出该持仓。机器人仍可能继续运行，其他网格也不会自动撤销。

### 完全停止

点击“停止 + 撤单 + 平仓”。系统会撤销全部未成交生产挂单、按最新可信价格平仓并对账。停止不会删除历史计划、订单、成交和收益。

若行情不可信，系统可能无法安全平仓并进入异常状态。此时不要连续重复点击，应先恢复可信行情并核对委托和持仓。

## 状态速查

| 状态 | 含义 | 用户动作 |
| --- | --- | --- |
| 已停止 | 没有运行中的生产网格 | 生成预览后可启动 |
| 新周期待启动 | 旧周期已结束，本周期未启动 | 重新检查参数 |
| 启动中 | 正在建计划和提交订单 | 等待，不要重复点击 |
| 运行中 · N 笔挂单 | 已接受 N 笔 paper 订单 | 到“当前委托”核对 |
| 调整网格中 | 正在撤旧单并重挂 | 等待完成 |
| 停止中 | 正在撤单、平仓和对账 | 等待完成 |
| 运行异常：0 笔挂单 | 运行状态与订单事实不一致 | 停止后重新启动并核对 ledger |
| 行情异常·停止新开仓 | 行情未通过可信门控 | 等行情恢复，不要绕过 |

## 交给别人前仍需明确的边界

1. 当前是共享 paper 机器人，不是每位用户独立账户。
2. 当前没有“只读 / 可调参 / 可平仓 / 管理员”的细粒度角色。
3. “价格冲出区间时”的多个自动动作仍需单独做端到端执行证明，不能代替人工止损纪律。
4. 统计重置只记录基线时间，账户总览是否按该基线完整截断仍需核对。
5. Strategy Shadow 当前是历史 smoke comparison；成本模型仍需完善，不能作为直接晋级生产的唯一证据。

当前推荐的外部使用方式：**一个指定操作人 + 其他人只观察 + PAPER 环境**。
