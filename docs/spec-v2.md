# 交易台 v2 需求说明（2026-09-14，Park 已授权直接开发）

## 目标
交易台是 Park 做交易的唯一入口：看新闻、看日报、判断、执行策略、盯盘、复盘都在这一个页面完成，不需要再去后台或别的页面。

## 页面结构
顶部三个标签：**交易** · **日报** · **系统**

### 交易（在 v1 基础上改）
- 品种不再写死：从 desk.db 的品种表读取。默认有 BTC 和黄金。
- 看：K 线旁边增加「K 线日报解读」卡片，读当天 K 线日报对这个品种的位置、结构和综合结论（数据来自 article.json）。
- 批准 → 执行（关键安全设计）：
  1. 点「批准这份计划」：交易台调用 Dashboard 做**预览**，显示真实的价位、止损、最多亏多少和风险检查结果。**这一步不下单。**
  2. 预览通过后出现「执行」按钮。必须 Park 本人在浏览器里按下这个按钮，才会提交确认并启动下单。
  3. 定时器、打开页面、刷新页面都不会触发执行。
  4. 目前只支持 Hyperliquid 测试盘。已有网格在跑时拒绝执行，并写明「先停当前网格」。黄金纸面盘暂不支持前端执行，页面上写明。
- `/api/health` 如实声明：`submits_orders: true, requires_human_press: true`。

### 日报
- 今日晨报：嵌入 `park-ai-intel/public/daily/latest.html`。它已经合成了 AI 日报、财经日报和 K 线日报三份。
- 可以翻看过去几天的晨报（`~/park-hands/009_morning brief/`）。
- K 线日报原文和宏观 K 线周报，各给一个入口。

### 系统
- 数据源健康：Intel 8001、Dashboard 8765、行情接口、网格记录、晨报、K 线日报，每项显示 ok 或异常，以及异常原因。
- 交易后台：调度器状态、网格上次检查时间。
- 已暂停的服务：列表，附恢复方法。

### 品种管理（前端加减品种）
- 「添加品种」：从交易所目录里选（Hyperliquid 测试盘的全部品种），自动填好交易所、合约代码、K 线来源和新闻关键词，可以手动改关键词。
- 删除品种：只从交易台里移除，不影响交易所上的任何东西。
