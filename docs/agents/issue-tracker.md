# Issue tracker: GitHub

Issues and specs for this repository live in GitHub Issues for
`zinan92/trading-system`. Use the `gh` CLI for tracker operations.

## Conventions

- Create an issue with `gh issue create` and a complete Markdown body.
- Read the exact issue and its labels back with `gh issue view` before
  reporting its URL.
- Add comments with `gh issue comment`; update labels with `gh issue edit`.
- Close issues only when their accepted outcome is complete.
- Pull requests are not an external request or triage surface.

## Skill interpretation

- When a skill says "publish to the issue tracker", create a GitHub Issue.
- When a skill says "fetch the relevant ticket", read the exact GitHub Issue
  and its comments.
- A specification Issue is the independent contract and acceptance anchor for
  later tickets and implementation.
