# Domain Docs

This repository uses a single-context domain model.

## Before exploring

- Read the root `CONTEXT.md`.
- Read the ADRs under `docs/adr/` that affect the area being changed.
- Proceed silently if a referenced domain document does not yet exist.

## Vocabulary

Use the glossary's canonical terms in specifications, issue titles, test names,
and implementation discussions. Do not substitute a term listed under
`_Avoid_` for its canonical concept.

If a needed concept is missing, resolve it through domain modeling before
silently inventing a synonym.

## ADR conflicts

If a proposed specification or implementation contradicts an existing ADR,
surface the conflict explicitly. Do not silently override an accepted decision.
